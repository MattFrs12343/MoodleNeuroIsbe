# Manual do Usuário — Plataforma Educativa (pt-BR)

> Documentação para os **usuários finais** (o Dr. e as pessoas autorizadas).
> Versão 1.0 · 2026-08-28 · Interface em **português do Brasil**.

---

## 1. O que é esta plataforma
A plataforma organiza, em **módulos**, todos os materiais das aulas:
- **Vídeos** (assistir online e baixar pelo Dropbox).
- **Áudios** (MP3).
- **Documentos** (PDF, Word, TXT).

Estrutura: **Módulo → Unidade → Recurso**.

## 2. Primeiro acesso

1. Entre no endereço da plataforma (URL informada pelo admin).
2. Clique em **"Entrar"** (canto superior).
3. Se ainda não tem conta: clique em **"Criar conta"**.
4. Preencha **nome, e-mail e senha**.
5. Aceite o **Aviso de Privacidade** (obrigatório).
6. Pronto! Você vai cair na **página inicial com os módulos**.

> Se você já tem conta: basta informar e-mail e senha em "Entrar".

## 3. Navegar pelos módulos

1. Na página inicial, visualize as **tarjetas dos módulos** (`Módulo 01`, `Módulo 02`, ...).
2. Clique na tarjeta do módulo desejado.
3. Dentro do módulo, veja as **unidades** (seções) na ordem de estudo.
4. Clique na unidade para ver os **recursos** daquela aula.

## 4. Assistir a um vídeo

1. Abra a unidade/aula do vídeo.
2. O vídeo aparece como **player incorporado** (YouTube).
3. Clique em **play**; use o botão de tela cheia se quiser.
4. Para **baixar o vídeo**: clique no botão **"Baixar vídeo"**, que abre o **Dropbox** e inicia o download.

> Dica: o download é feito pelo Dropbox; o arquivo não fica armazenado na plataforma.

## 5. Ouvir um áudio (MP3)

- Dentro da unidade, clique no recurso de áudio → o player abre e você pode reproduzir ou baixar.

## 6. Ver documentos

| Tipo | O que acontece |
|---|---|
| **PDF** | Abre para leitura direto na plataforma (ou baixa). |
| **Word (docx)** | Inicia o download para abrir no Word. |
| **TXT** | Abre como texto na própria página. |

## 7. Problemas comuns

| Problema | Solução |
|---|---|
| Esqueci a senha | Clique em **"Esqueceu seu e-mail ou senha?"** na tela de login. |
| Vídeo não carrega | Verifique sua internet; recarregue a página; se continuar, avise o admin. |
| Download Dropbox não inicia | Confirme que está logado no Dropbox; avise o admin se houver erro. |
| Não vejo um módulo | É possível que ainda não foi publicado; contate o admin. |

## 8. Privacidade e seu perfil

- Você pode **apagar sua conta** solicitando ao admin (contato informado na plataforma).
- Seus dados são tratados conforme o **Aviso de Privacidade** e a **LGPD** (lei brasileira).
- Material das aulas é **de uso restrito**: não compartilhe vídeos/links com terceiros.

## 9. Acesso de emergência / contato

Para suporte, escreva para o administrador da plataforma (e-mail na tela inicial ou no
rodapé). Descreva: a tela onde está e a mensagem de erro apresentada (se houver).
