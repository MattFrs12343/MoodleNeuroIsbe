Se resolvio con el mecanismo OFICIAL de Moodle para personalizar strings sin tocar core: un archivo de idioma local en `$CFG->dataroot/lang/pt_br_local/moodle.php` con `$string['welcomeback']=''` y `$string['welcometosite']=''` -- Mustache trata una seccion `{{#welcomemessage}}` con string vacio como falsy, asi que ni siquiera queda un div vacio (confirmado en `lib/templates/welcome.mustache`). Copia versionada en `src/lang/pt_br_local/moodle.php`. Para el saludo nuevo en "Meus cursos": no hay forma de obtener el nombre del usuario logueado de forma confiable solo con JS/CSS (Moodle 4.5 no expone el fullname en ningun elemento visible del header, solo iniciales en el avatar) -- se agrego un metodo `standard_top_of_body_html()` al renderer propio del tema (`classes/output/core_renderer.php`, ya existente para el logo), que es el punto de extension OFICIAL de Moodle para inyectar HTML justo despues de `<body>` en TODAS las paginas sin tocar plantillas de core; se usa solo para dejar el nombre de pila del usuario en un `<span hidden>` cuando `$this->page->pagelayout === 'mycourses'`. El script de `additionalhtmlfooter` (mismo patron que constelaciones/splash) lee ese dato y arma el widget visual: circulo con icono SVG de estetoscopio (path propio, con `<linearGradient>` de $blue-deep a $sky vía SVG nativo, no CSS) + "Ola, {Nombre}!" + subtitulo "Bem-vindo(a) de volta aos seus cursos.", insertado justo antes de `.block-myoverview`. El nombre se inserta por `textContent` (no concatenado en el HTML) para no mezclar un valor de la BD con marcado. Verificado con Chrome headless + CDP logueando de verdad: la Pagina Principal ya NO tiene "Ola" en ningun lado del texto visible; "Meus cursos" tiene `.platform-greeting` con el texto exacto "Ola, Administrador!" + SVG presente.
